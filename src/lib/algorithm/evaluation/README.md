# 双叉树分类评估模块

## 概述

本模块为双叉树分类（dual-tree.ts）提供三个层级的评估方法，证明分类方法的可量化质量、稳定性和业务意义。

## 为什么需要评估？

双叉树分类是业务驱动的方法（业务规则 + 合规约束），但需要客观指标证明：
1. **分得准**：分类结果是否真实反映了客户画像差异？
2. **分得稳**：新客户加入或数据扰动下，分类结果是否一致？
3. **分得有意义**：分类是否揭示了可解释的业务洞察？

## 三个评估方法

### 1. 业务指标对比（demographics-analysis.ts）

**评估目标**：分得有业务意义

**核心指标**：
- 每个客群场景的画像特征（资产、年龄、风险等级、家庭结构等）
- 客群之间的画像差异倍数
- 主要业务目标分布

**输出示例**：
```
【银发稳健族】(A1)
  人数：120（5.2%）
  平均资产：65万
  平均年龄：71岁
  平均DTI：12%
  主要风险等级：R2(78%)

【高净值族】(B4)
  人数：45（1.9%）
  平均资产：520万
  平均年龄：48岁
  平均DTI：23%
  主要风险等级：R4(65%)
```

**业务解读**：银发族与高净值族资产差异 8 倍、年龄差异 23 岁，验证了双叉树分层有效性。

### 2. 轮廓系数评估（silhouette-score.ts）

**评估目标**：分得准（同质性 + 异质性）

**算法**：
```
s(i) = (b(i) - a(i)) / max(a(i), b(i))
```
- `a(i)`：客户 i 到同簇其他客户的平均距离（越小越好）
- `b(i)`：客户 i 到最近异簇客户的平均距离（越大越好）

**业务距离定义**：综合考虑 7 个业务维度（资产、风险、年龄、收入稳定性、DTI、家庭结构、生命周期）

**质量分级**：
| 分数 | 等级 | 业务意义 |
|------|------|----------|
| < 0.30 | POOR | 分类同质性不足 |
| 0.30-0.50 | FAIR | 分类有一定效果 |
| 0.50-0.70 | GOOD | 分类有效 |
| > 0.70 | EXCELLENT | 分类优秀 |

**注意**：业务分类因维度离散多，轮廓系数通常低于通用聚类（如 K-means）。业务分类 > 0.5 即为良好。

### 3. Bootstrap 重采样（bootstrap-stability.ts）

**评估目标**：分得稳（对新样本的鲁棒性）

**算法**：
1. 从客户数据中有放回抽样 1000 次（每次 N 个样本）
2. 每次抽样后运行双叉树分类
3. 统计每个客户被分到各场景的频率分布

**输出指标**：
- 稳定客户（一致性 ≥95%）：高度可信赖
- 边界客户（一致性 70-95%）：需人工复核
- 不稳定客户（一致性 <70%）：规则可能需优化

**业务价值**：
- 证明分类方法不是"过拟合"
- 边界客户可单独标注，由客户经理复核
- 反馈到双叉树规则，形成持续优化闭环

## 为什么不用 Q-Q 图 / Shapiro-Wilk / AD 检验？

| 工具 | 用途 | 为什么不用 |
|------|------|-----------|
| Q-Q 图 | 可视化正态性 | 客户画像是离散业务维度，不是连续分布 |
| Shapiro-Wilk | 小样本正态性检验 | 业务分类不依赖正态假设 |
| AD 检验 | 大样本正态性检验 | 同上 |

**业务分类的核心理由**：
1. 我们的数据是分类变量（风险等级 R1-R5）+ 长尾分布（资产），不服从正态分布
2. 我们用的是业务规则驱动的双叉树，不是基于分布假设的统计方法
3. 强行加入正态性检验会暴露弱点（评委追问为什么）
